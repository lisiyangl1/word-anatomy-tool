单词解剖台 · Word Anatomy  —— 使用说明书
单文件纯前端单词解析工具（HTML + Tailwind CSS v3 + 原生 JS）
生成时间：2026-11-17
========================================================

一、怎么用
--------------------------------------------------------
1. 双击 word-anatomy.html，用 Chrome / Edge / Safari 打开即可，无需服务器、无需安装。
2. 输入英文单词 → 点「解析」或直接回车。
3. 也可以：点示例词 / 点「随机」/ 地址栏加 ?w=computer 直达（可分享链接）。
4. 快捷键："/" 快速聚焦输入框，Esc 清空输入。

二、页面上的五层信息
--------------------------------------------------------
① 词头   单词 + 等级标签（CET-4 / CET-6 / 基础词）+ 一键复制
② 音标   英音 UK、美音 US，点击音标卡可用系统语音朗读
③ 音节   带间隔点的音节拆分（如 in·for·ma·tion）
④ 词根词缀 用颜色区分：蓝=前缀、红=词根、绿=后缀、灰=词干，
          每个色块下方直接给出该部分的释义，底部附词源小注
⑤ 释义例句 多条中文释义，每条配英文原句 + 中文译文，目标词自动高亮；
          若该词只有一条例句，第二条起会标注「共用例句」
⑥ 同义词 标签形式，点一下即自动填入输入框并查询

三、词库规模与来源
--------------------------------------------------------
· 共 7536 个词条，每条约含：英美音标、词性+中文释义、1~2 条例句（带译文）、0~6 个同义词。
· 覆盖：CET-4 全部词 + CET-6 全部词（四六级词书合并去重 6662 条），
  另补高中/初中基础词，避免出现查不到 run / think / work 这类情况。
· 词条数据已内嵌在 HTML 里，查询过程零网络请求。

四、词根词缀是怎么拆的（规则说明）
--------------------------------------------------------
拆解引擎按「最长匹配 + 多重校验」工作：
1. 先取最长前缀（如 inter 优先于 in，com 优先于 co），
   要求剥掉前缀后剩下的部分「本身是词 / 含已知词根 / 能再带后缀」，
   且不跨越「元音-元音」边界，否则判定不是前缀。
2. 再取最长后缀（-ation 优先于 -ion），要求剥掉后词干 ≥3 个字母，
   且词干成词、或是词根、或足够长（≥5），避免把 color 拆成 col+or。
3. 词干部分：整体命中词根 → 词根；能连续拆成两段词根（bio+techno）→ 多词根；
   词根 + 1~2 个残余字母 → 归入词根；否则标为「词干」并给中文义。
4. 拆不开的词（如 abandon、apple、window）：直接告诉你
   「原生词 / 单根词，不可再拆，建议整体记忆」，其余模块照常显示。
5. 内置约 60 条人工精讲词条（unbelievable、international、extraordinary 等），
   命中精讲时优先使用人工拆解与词源小注，更准确。

注意：规则拆解面向「辅助记忆」，少数词的历史词源与显示结果可能略有出入，
页面会在自动拆解结果下方标注提示；想更精确就把它加入人工精讲表（见第六节）。

五、交互与视觉细节
--------------------------------------------------------
· 输入框聚焦：边框 0.35s 平滑变色 + 柔光环（不跳动、不闪烁）
· 解析按钮：按下有波纹扩散 + 轻微缩放反馈
· 查询过程：按钮转圈 + 结果区骨架屏 + "正在解析 xxx…"
· 结果呈现：整块淡入上滑，五个模块依次错开 40~60ms 入场
· 折叠：每个模块标题可点，高度用 max-height 过渡（0.42s），箭头同步旋转
· 释义卡：hover 上浮 4px + 阴影加深
· 复制：右上角「复制」按钮导出完整文本解析（音标/音节/词根词缀/释义例句/同义词），
  成功后底部弹出 Toast 提示；剪贴板不可用时自动降级到 execCommand
· 移动端：≤640px 自动单列、音标卡上下堆叠、标签自动换行
· 无障碍：折叠按钮带 aria-expanded，结果区 aria-live，尊重系统「减少动效」设置

六、想自己加词 / 改词？改这三处就行
--------------------------------------------------------
打开 HTML，搜索对应标记：

1) 加普通词条 —— 搜索 `const WORDS`，这是 JSON 数组，按格式追加一条：
   {"w":"单词","lv":["CET4"],"uk":"音标","us":"音标",
    "tr":[["词性","中文释义"],["n","第二释义"]],
    "ex":[["English sentence.","中文译文"]],
    "sy":["同义词1","同义词2"]}
   lv 可写 CET4 / CET6 / 基础 / 扩展。

2) 加人工精讲（推荐给难词）—— 搜索 `const CURATED`，追加：
   believe:{ syl:'be·lieve',
     segs:[['be','pre','加强'],['lieve','root','相信']],
     note:'词源小注……' }
   segs 按顺序拼接必须正好等于原词，类型用 pre / root / suf / stem / base。

3) 加同义词补充 —— 搜索 `const SYN_EXTRA`，格式 `word:['a','b','c']`。
   词条自带同义词少于 3 个时会自动并入。

想扩充音节例外（算法拆错的词）—— 搜索 `SYL_EXCEPTIONS` 加一条
`word:'sy·lla·ble'` 即可覆盖自动结果。

七、技术实现速览
--------------------------------------------------------
· 样式：Tailwind CSS v3（CDN JIT）负责布局与间距，配色/动效由 CSS 变量自定义；
  Tailwind 没加载成功时页面仍可正常查询（内容不走 Tailwind）。
· 动画：全部为 CSS transition + @keyframes（fadeUp / ripple / shimmer / spin）。
· 数据：7536 条词条以 JSON 内嵌，启动时建 Map 索引，O(1) 查词。
· 查词容错：词形还原（studied→study、running→run、happier→happy）；
  查不到时用编辑距离给 6 个候选词，点击即可查。
· 文件大小约 2.4 MB（主要是词库），本地打开即用，无任何后端与接口。

八、已知限制
--------------------------------------------------------
1. 单词查询，不支持词组（"give up" 这类暂不解析）。
2. 音节与部分词根拆解是规则算法，个别词可能不准（可用 SYL_EXCEPTIONS / CURATED 覆盖）。
3. 同义词来自词库原始数据，偶有语义偏移（如 abandon 的 mania）。
4. 音标朗读依赖系统语音包，无语音包的环境点了不会出声，不影响其它功能。
5. Tailwind CDN 需要联网；完全离线时版式会退化（功能不受影响）。
   若需完全离线：把 CDN 换成本地 tailwind.css 即可。
